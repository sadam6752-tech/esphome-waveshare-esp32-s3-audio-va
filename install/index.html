Waveshare Voice

Voice satellite firmware for the Waveshare ESP32-S3-AUDIO-Board, driven by ioBroker.assistant. Flash it from this page with Chrome or Edge on a computer; no ESPHome build needed.

With display

With the Waveshare 2.8inch Capacitive Touch LCD on the LCD connector.

Use Chrome or Edge on a computer. Open this page over https.

Without display

The board alone: speaker, microphones, LED ring, buttons.

Use Chrome or Edge on a computer. Open this page over https.

Steps

  1. Connect the board with a USB-C cable and press Install. If no port shows up, hold BOOT while plugging the cable in.
  2. After flashing, the page offers to set up Wi-Fi. With the display, Wi-Fi can also be set on the device: Settings (gear) > Wi-Fi. Without a network the board opens the access point Waveshare-VA Setup; join it with a phone and pick your network.
  3. In ioBroker.assistant, add the satellite (Satellites tab). Later updates show up there as the Firmware update.
